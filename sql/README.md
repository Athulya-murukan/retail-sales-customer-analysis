# SQL Analysis

This folder contains SQL queries used to analyse retail sales and customer purchasing behaviour.

## SQL Skills
- SELECT and WHERE statements
- GROUP BY and ORDER BY
- Aggregate functions
- JOIN operations
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions

## Business Questions
- What are the total sales and revenue?
- Which products generate the highest revenue?
- Which countries have the highest sales?
- Who are the top customers?
- What are the monthly sales trends?
