# Retail Sales & Customer Analysis

## Project Overview
This project focuses on analysing retail sales data to identify sales trends, customer purchasing behaviour, and business performance.

The goal is to transform raw retail data into meaningful insights that can support better business decisions.

## Objectives
- Analyse overall sales and revenue.
- Identify top-performing products.
- Explore sales performance across countries.
- Understand customer purchasing behaviour.
- Identify trends and patterns in retail transactions.
- Provide data-driven business recommendations.

## Tools & Technologies
- Microsoft Excel
- Python
- SQL
- Power BI

## Project Workflow
1. Data collection and understanding
2. Data cleaning and preparation
3. Exploratory Data Analysis (EDA)
4. SQL-based business analysis
5. Interactive Power BI dashboard
6. Insights and recommendations

## Dataset
Source: UCI Machine Learning Repository – Online Retail Dataset.
